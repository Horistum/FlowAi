# Flow Core v0.8.1 Release Report

## Objective

v0.8.1 introduces the Target Capability Matrix package-level work.

## Scope

The release adds a descriptive matrix over registered target capabilities. It validates that required targets are present, core capability dimensions are represented, unsupported capabilities remain explicit, and target metadata is not blank.

## Added

- `TargetCapabilityMatrixAnalyzer`
- `TargetCapabilityMatrixReport`
- `TargetCapabilityMatrixEntry`
- Regression tests for repository targets and invalid target metadata
- Documentation for the target capability matrix

## Boundaries

This release does not add runtime execution, SDK APIs, plugin lifecycle, target-specific public DSL, renderer expansion or Flow syntax changes.

## Validation

Validation is expected through Flow CI:

- Gradle clean test
- Flow conformance

## Next

The next roadmap item is v0.8.2 Target Negotiation Report.
