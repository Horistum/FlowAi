# v0.9.5.5 Materialization Negotiation

## Summary

v0.9.5.5 adds a target-neutral negotiation layer above the Universal Semantic Action Graph.

The negotiation layer records the materialization status of every semantic action node before any later projection step can claim support.

## Added

- `MaterializationStatus`
- `MaterializationEvidenceKind`
- `MaterializationEvidence`
- `MaterializationDecision`
- `MaterializationNegotiation`
- `MaterializationNegotiationValidator`
- `StandardMaterializationNegotiations`
- `FlowMaterializationNegotiationTests`
- `docs/V0_9_5_5_MATERIALIZATION_NEGOTIATION.md`

## Correction result

Every semantic action now requires an explicit materialization decision. Missing, duplicated, unknown or unsupported decisions are reported instead of being inferred as successful.

Runtime, target and projection requirement nodes cannot bypass their boundary by being marked materializable too early.

## Versioning boundary

- Current package version remains `0.9.4`.
- Active public standard version remains `0.7.6`.
- No artifact schema version is changed.
