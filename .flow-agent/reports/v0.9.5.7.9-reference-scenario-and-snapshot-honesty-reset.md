# v0.9.5.7.9 Reference Scenario and Snapshot Honesty Reset

## Purpose

Reset reference scenarios and snapshots so committed evidence states exactly what the real parser, planner, compatibility, materialization and render pipeline can prove.

## Implemented

- Flagship build/test intent now lowers through semantic `standard.execute`, not active shell execution.
- Adapter expectations require exact executable, review-only or fail-fast evidence.
- Snapshot filenames and `snapshot-index.json` expose current projection state explicitly.
- Legacy executable-looking files and stale compatibility/manifest placeholders are rejected.
- Conformance performs exact canonical comparisons and fails on drift.
- Snapshot documentation no longer describes review artifacts as end-to-end execution proof.

## Validation

The standard Flow CI workflow is the only final merge gate. It must pass Flow Agent tooling, structure validation, context generation, clean tests and full conformance on the persisted clean branch.
