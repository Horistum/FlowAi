# AI-A3-S3.10 Independent planning portfolio review

PR #277 commissioned a Kubernetes field update and independent runtime observation. The next roadmap gate concerns live **planning** performance across independently chosen requests. The S3.5 evaluator already freezes inputs, reserves repeated worker turns and independently checks selected plans. Its configured model name and completion count alone cannot establish exposure history, live provider provenance or whether a formally accepted plan addresses the original goal.

The new external review entry point registers the case split, domain scope, separate custody keys and evidence class before the first reservation. It uses the existing evaluator, worker recovery and canonical compiler review. Its registration digest is retained outside the evaluation directory. Neither the existing worker authority identity nor the public compiler contract changes.

The provider custodian signs separately captured turn records. The reviewer signs individual decisions bound to both the exact provider export and a recomputed review request. The join checks the effective model, distinct session, turn, task boundaries, ordered draft contents and observation snapshots, and final selection. Compiler and reviewer disagreement remains visible. Per-domain coverage and held-out results apply to the entire registered matrix, including blocked trials. Unknown costs stay unknown.

## Proof and scope

The installed CLI proof uses an explicitly scripted peer with an independent test-side capture of the traffic it actually received. Three repetitions each exercise infrastructure readiness, isolated data recovery and a compiler-accepted wrong-goal recovery. Six of nine selections satisfy requirements. The wrong-goal selections fail independent review. Tampered decisions, role substitution, missing or duplicate turn records, changed drafts, relabelled evidence, a substituted registration digest and retroactive registration are rejected. Verification consumes no replacement turns.

This is protocol and compiler evidence. No private reviewed live portfolio or commissioned provider capture was supplied for this development run.
