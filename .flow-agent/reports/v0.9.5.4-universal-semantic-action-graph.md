# v0.9.5.4 Universal Semantic Action Graph

## Summary

v0.9.5.4 adds a target-neutral semantic action graph model for the architecture recenter correction track.

The graph provides a structured place for Flow semantic meaning before runtime negotiation, target projection and materialization. It is intentionally not an executable plan, renderer, SDK entrypoint, plugin lifecycle, shell projection or command representation.

## Added

- `SemanticActionKind`
- `SemanticActionEdgeKind`
- `SemanticActionNode`
- `SemanticActionEdge`
- `SemanticActionGraph`
- `SemanticActionGraphValidator`
- `StandardSemanticActionGraphs`
- `FlowSemanticActionGraphTests`
- `docs/V0_9_5_4_UNIVERSAL_SEMANTIC_ACTION_GRAPH.md`

## Validation boundary

The validator enforces notes package binding, node and graph identity, edge integrity, acyclic structure and prohibition of command or shell vocabulary as universal semantic action meaning.

## Correction result

The project now has an internal universal semantic action graph boundary that can be used by later correction items without treating a target renderer or command string as semantic truth.

## Versioning boundary

- Current package version remains `0.9.4`.
- Active public standard version remains `0.7.6`.
- No artifact schema version is changed.
- No runtime executor, SDK API, plugin lifecycle, target-specific public DSL, renderer expansion, target materialization or Flow syntax change is introduced.
