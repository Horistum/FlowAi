# v0.8.4 Planner Capability Constraints Report

## Objective

Add an explicit pre-projection capability gate between platform-neutral planning and target manifest projection.

## Scope

Included:

- `PlannerCapabilityConstraintGate`
- `PlannerCapabilityConstraintReport`
- `PlannerCapabilityConstraintStatus`
- Regression tests for allowed, degraded, blocked, strict-mode and unknown-target outcomes
- v0.8.4 documentation
- v0.8.4 release metadata

## Behavior

The gate uses the existing `CompatibilityAnalyzer` and target capability registry.

It classifies a plan-target pair as:

| Status | Meaning |
| --- | --- |
| `ALLOWED` | The plan can be projected without warnings. |
| `DEGRADED` | The target has partial support; projection may continue outside strict mode with explicit compatibility warnings. |
| `BLOCKED` | The target cannot represent required semantics, or strict mode promoted partial support to blocking errors. |
