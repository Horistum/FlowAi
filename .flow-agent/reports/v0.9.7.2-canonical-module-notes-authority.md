# v0.9.7.2 Canonical Module and Notes Authority

## Outcome

Module capability and safety contracts now load from one strict descriptor directory. Hardcoded registry copies were removed, malformed shapes and duplicate identities fail closed, and explicit approval requirements are preserved.

Core notes contracts now load from one versioned manifest and package directory. Concrete implementation declarations remain outside the Core authority.

The ArgoCD module no longer carries implementation compatibility claims.

## Boundary

No new planning, materialization, renderer or implementation capability behavior was introduced. Package, public standard and artifact contract versions remain unchanged.

Flow CI 1557 passed the implementation head, including compilation, full tests, full conformance and executable reference evidence. The final metadata head must pass the same checks.
