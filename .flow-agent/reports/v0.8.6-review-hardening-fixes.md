# v0.8.6 Review Hardening Fixes

## Scope

This package applies the two uploaded review-fix patches as one implementation line on top of the current `main` state after v0.8.5 runtime input environment rendering.

## Included changes

- Materialises system secrets through target-native secret mechanisms instead of dropping `secret("NAME")` system config.
- Binds rendered secret references through `FLOW_SECRET_*` environment variables for Jenkins, GitHub Actions and Tekton.
- Makes notification delivery failure non-zero instead of masking it with `|| echo`.
- Preserves explicit rollback negation in deployment and database migration scenario packs.
- Avoids hardcoded package/public-standard version drift in `VALIDATION.txt`.
- Treats non-HTTP all-caps barewords as references instead of symbolic literals.
- Isolates mutually exclusive branch result bindings while preserving sequential duplicate detection.
- Upgrades unknown result fields to errors when a module has a concrete output schema.
- Moves deprecated legacy draft generators out of production source and into test source for backward-compatibility tests.
- Adds regression tests for the fixed behaviours.

## Architectural boundary

This is a hardening/change-quality package only. It does not introduce a runtime executor, SDK-first plugin lifecycle, target-specific public DSL, new Flow syntax, public standard version bump or artifact schema bump.

## Required validation after import

```bash
./gradlew --no-daemon clean test --stacktrace --console=plain
./gradlew --no-daemon run --args="conformance" --stacktrace --console=plain
```
