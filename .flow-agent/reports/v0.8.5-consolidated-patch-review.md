# v0.8.5 Consolidated Patch Review

## Source package

Reviewed uploaded package: `FlowAi-main-patched.zip`.

The package appears to be based on package line `0.8.2`, while GitHub `main` is already at package line `0.8.5`. The uploaded tree must therefore not be applied as a full replacement.

## Accepted changes applied to this branch

- Hardened template interpolation brace matching in `ExpressionParser` so braces inside quoted string literals do not terminate `${ ... }` parsing.
- Preserved target system configuration at the planner boundary for non-secret defaults consumed by `git`, `rest`, `kubernetes`, and `helm` actions.
- Explicit action parameters still override system defaults.
- Secret-valued system configuration is intentionally not lowered into literal plan parameters.

## Reviewed changes not applied in this branch

The uploaded package also includes target manifest/runtime-input rendering changes that move runtime input values through `FLOW_*` environment variables for Jenkins, GitHub Actions, and Tekton. Conceptually this is a good direction because it avoids injecting runtime user input directly into shell script literals.

Those renderer and snapshot changes were not applied in this branch because they touch large generated target files and should be merged as a focused follow-up patch with local Gradle validation and regenerated snapshots. Applying the whole uploaded file would also risk overwriting newer `0.8.5` work with older `0.8.2` package content.

## Versioning decision

No package version bump is included here. This is a review-fix branch against `0.8.5`, not a new package release.
