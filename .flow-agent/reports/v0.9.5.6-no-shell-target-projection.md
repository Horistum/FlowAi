# v0.9.5.6 No-Shell Target Projection

## Summary

v0.9.5.6 adds the target projection plan contract for the architecture recenter correction track.

The projection plan records artifact intent after materialization negotiation. It keeps target-native, notes-backed, adapter-boundary, review and conformance records separate so projection cannot fall back to generic command representation.

## Added

- `TargetProjectionArtifactKind`
- `TargetProjectionArtifact`
- `TargetProjectionPlan`
- `TargetProjectionPlanValidator`
- `StandardTargetProjectionPlans`
- `FlowNoShellTargetProjectionTests`
- `docs/V0_9_5_6_NO_SHELL_TARGET_PROJECTION.md`

## Validation focus

The validator checks artifact coverage, known semantic nodes, materialization status alignment, target-native boundary declarations, notes-backed references, adapter-required boundaries and unavailable decision records.

It also rejects shell, command, script and related vocabulary as projection representation.

## Correction result

The project now has a no-shell projection contract that can be used before tightening existing renderer behavior.

This does not claim that target renderers are complete. It defines the projection shape and honesty checks required before such claims can be made.

## Versioning boundary

- Current package version remains `0.9.4`.
- Active public standard version remains `0.7.6`.
- No artifact schema version is changed.
