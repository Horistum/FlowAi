# Flow Core v0.8.2 Release Report

## Objective

v0.8.2 introduces a target negotiation explanation report.

## Scope

The release builds on the existing compatibility negotiation model and converts its lower-level data into a clear report with supported, degraded and blocked outcomes.

## Added

- `TargetNegotiationReportAnalyzer`
- `TargetNegotiationExplanationReport`
- `TargetNegotiationExplanation`
- `TargetNegotiationRejectionReason`
- `TargetNegotiationOutcome`
- Regression tests for supported, degraded, blocked and runtime-required target outcomes
- Documentation for the target negotiation report

## Boundaries

This release does not add runtime execution, SDK APIs, plugin lifecycle, target-specific public DSL, renderer expansion, planner changes or Flow syntax changes.

## Validation

Validation is expected through Flow CI:

- Gradle clean test
- Flow conformance

## Next

The next roadmap item is v0.8.3 Planner Capability Constraints.
