# v0.9.5.7.4 Remove Legacy Shell Generator Fixtures

## Summary

This repair removes the remaining active test implementations and assertions that encoded shell-oriented target generation as correct Flow behavior.

## Changed

- Deleted the legacy Jenkins test generator.
- Deleted the legacy GitHub Actions echo generator.
- Replaced the monolithic `FlowSpecTests_part2.kt` harness with responsibility-based test files.
- Preserved language, validation, planner, example, module, source-location and stress coverage.
- Replaced legacy generator smoke tests with the production manifest and renderer-readiness path.
- Added JUnit regression coverage for physical source removal and cross-target blocked shell behavior.

## Result

The active test source set no longer contains an implementation that maps Flow actions to Jenkins shell steps, GitHub Actions echo steps, container CLI, cluster CLI, chart CLI or deployment CLI commands.

The four remaining shell syntax examples are retained only as migration and language fixtures. Their explicit command values remain visible for review, while materialization is required to be `BLOCKED` and renderer readiness is required to be `FAIL_FAST` for Jenkins, GitHub Actions and Tekton.

## Validation boundary

This repair does not replace the shell-based reference scenarios with universal semantic actions. The corpus reset remains assigned to v0.9.5.7.9. The current step removes legacy test implementations and prevents tests from presenting those scenarios as executable target generation.
