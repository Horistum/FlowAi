# v0.9.5.7.4 Remove Legacy Shell Generator Fixtures

## Summary

This repair removes the active test contract that encoded shell-oriented Jenkins generation as correct Flow behavior.

## Changed

- Replaced `src/test/kotlin/org/flowlang/generators/JenkinsGenerator.kt` with a compatibility tombstone.
- Removed `jenkinsGeneratorTests()` from the active JUnit specification bridge.
- Added `LegacyShellFixtureRemovalTests`.
- Classified all current `shell.run` examples as preserved but blocked runtime intent.

## Result

The test suite no longer protects direct Jenkins shell, Docker CLI, Kubernetes CLI, Helm CLI or Argo CD CLI projection.

Explicit command content remains available for review in the manifest, but every shell action is required to have `BLOCKED` materialization and `FAIL_FAST` renderer readiness. The compatibility tombstone fails immediately if an old caller attempts to use it.

## Validation boundary

This repair does not replace the shell-based reference scenarios with universal semantic actions. That corpus reset remains assigned to v0.9.5.7.9. The current step prevents legacy test code from presenting those scenarios as executable target generation.
