# v0.9.5.7.4 Remove Legacy Shell Generator Fixtures

## Summary

The compiled legacy Jenkins generator fixture has been removed from the active Gradle test source set.

## Changes

- Deleted the 372-line test generator that emitted Jenkins `sh`, concrete CLI commands and `echo` fallbacks.
- Removed obsolete generator-output assertions from `FlowSpecTests_part2.kt`.
- Added a structured, non-compiled archived negative fixture for the historical shell and CLI cases.
- Added executable regression coverage using the canonical manifest, materialization and renderer-readiness path.
- Added a structural gate preventing `JenkinsGenerator.kt` from returning to active Kotlin source roots.

## Expected semantics

- `shell.run`: `BLOCKED` / `FAIL_FAST`.
- historical concrete-tool actions: `ADAPTER_REQUIRED` / `REVIEW_ONLY`.
- no legacy case may emit Jenkins syntax or populate `TargetStep.run`.

## Version boundary

Package version remains `0.9.4`, public standard version remains `0.7.6`, and artifact schema versions are unchanged.
