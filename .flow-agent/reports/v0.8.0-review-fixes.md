# v0.8.0 Review Fixes

This follow-up records fixes from the post-merge review of v0.8.0.

## Fixed

- `deploy-with-approval.flow` now provides `app` to `kubernetes.deploy`, so the manifest generator path has an explicit deployment identity.
- Jenkins Groovy builtin regex patterns are escaped before being placed inside slash-delimited regex literals.
- Target interpolation no longer rewrites member paths such as `${deploy.status}` into fake runtime parameters.
- Scenario pack quality analysis now has direct regression tests.

## Still intentionally separate

`CoreContractCheck` is validated by unit tests and CI. Direct `ConformanceRunner` wiring is left for a separate refactor because the runner is currently large and should not be modified by a broad rewrite in this review-fix branch.

## Boundaries

No SDK API, runtime executor, plugin lifecycle, target-specific public DSL, renderer expansion or Flow syntax change was added.
