# v0.9.1 Jenkins/GitHub/Tekton Projection Stability

## Summary

v0.9.1 adds smoke-level projection stability guards for the main supported target renderers: Jenkins, GitHub Actions and Tekton.

The release focuses on renderer stability after the v0.9.0 generator projection contract. It verifies that real manifests produced from a real Flow example remain renderable into structurally recognizable target artifacts and do not regress to green placeholder commands.

## Added

- `ProjectionStabilitySmokeTests`
- `docs/V0_9_1_PROJECTION_STABILITY.md`

## Smoke coverage

The tests validate:

- Jenkins pipeline structure, parameters, environment, credentials binding, stages and shell steps
- GitHub Actions workflow_dispatch, jobs, runner structure, env binding, secrets binding and run blocks
- Tekton Pipeline structure, taskSpec, secretKeyRef binding and script blocks
- deterministic rendering for all three target renderers
- absence of `Flow executes ...` placeholder commands

## Validation expectation

GitHub Actions or local review must run:

```bash
./gradlew --no-daemon clean test --stacktrace --console=plain
./gradlew --no-daemon run --args="conformance" --stacktrace --console=plain
```
