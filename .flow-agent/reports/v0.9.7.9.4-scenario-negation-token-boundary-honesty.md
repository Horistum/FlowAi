# v0.9.7.9.4 Scenario Negation and Token Boundary Honesty

## Status

Implementation complete. Exact-head Flow CI validation is required before review readiness and is recorded on the pull request review surface.

## Corrected failures

- Scenario triggers used substring and non-contiguous ordered-token matching.
- `ci` could match inside unrelated words such as `capacity`.
- repository and notification systems were inferred from raw substrings.
- a bare `team` noun synthesized notification behavior.
- database migration converted `no backup` into a positive `BACKUP` step and `backup=required`.
- restore-only requests always created a new backup first.
- approval and rollback used separate hard-coded denial phrase lists.
- the contradiction validator maintained a second backup-negation vocabulary.

## Implemented design

`IntentSourceDirectiveAuthority` is the single lexical authority for source directive polarity. It tokenizes phrases at identifier-safe boundaries, detects clause-local prefix and suffix negation, records individual mention evidence and produces `REQUESTED`, `DENIED`, `CONFLICTING` or `ABSENT`.

Scenario selection counts only affirmed, contiguous trigger phrases. Scenario synthesis uses the same evidence for backup, repository/source, notification, approval, rollback and restore. Conflicting polarity becomes a required clarification and disputed work is withheld.

Trigger scoring combines independent phrase hits with exact lexical specificity. Multi-token intent phrases therefore outrank generic one-token nouns without relying on pack registration order. Database migration explicitly supports common article-bearing forms such as `migrate the database`.

Database migration now emits positive backup evidence only for an affirmed backup request. Explicit denial produces no backup step or positive backup parameter and remains blocked by normal safety/control requirements. Restore-only requests no longer invent a fresh backup.

The independent contradiction authority remains active and consumes the shared lexical evidence as defense in depth.
