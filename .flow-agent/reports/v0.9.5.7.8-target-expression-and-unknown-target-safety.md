# v0.9.5.7.8 Target Expression and Unknown Target Safety

## Purpose

Ensure expression support is derived from explicit target evidence and that unknown targets fail closed instead of inheriting implicit capability.

## Required outcomes

- unknown targets do not silently pass expression support checks
- expression support is declared through target notes, capability or registry evidence
- compatibility analysis and target translation consume the same support decision
- target-specific expression knowledge is isolated from universal Flow semantics
- unsupported expressions remain blocked before target syntax is emitted

## Architecture boundary

This correction does not introduce runtime execution, an SDK, a framework lifecycle, shell projection, target-specific public Flow syntax or renderer payload expansion.
