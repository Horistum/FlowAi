# v0.9.5.7.3 Renderer Failure Semantics Unification

## Summary

v0.9.5.7.3 replaces target-specific unresolved execution artifacts with one review-only rendering policy.

## Added

- `TargetRenderMode`
- `TargetRenderFinding`
- `TargetRenderDecision`
- `TargetRenderPolicy`
- `TargetReviewArtifactRenderer`
- `FlowRendererFailureSemanticsTests`

## Corrected

- Jenkins no longer emits unresolved action failures as a generated pipeline substitute.
- GitHub Actions no longer emits `steps: []` jobs for unresolved work.
- Tekton no longer references a phantom `flow-materialization-required` Task.
- `NOTES_PROJECTED` is no longer interpreted as target-native executable evidence.

## Current result

The current reference manifests are review-only because they do not carry explicit target-native projection evidence. Their rendered artifacts declare `mode: REVIEW_ONLY` and `executable: false` and list unresolved steps with materialization reasons.

Historical snapshot filenames remain in place until v0.9.5.7.9 resets reference scenario and snapshot naming.
