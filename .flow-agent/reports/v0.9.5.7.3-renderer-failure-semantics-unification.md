# v0.9.5.7.3 Renderer Failure Semantics Unification

## Summary

This repair introduces a shared readiness policy for Jenkins, GitHub Actions and Tekton rendering.

## Added

- `TargetRenderMode`
- `TargetRenderReadiness`
- `TargetRenderFinding`
- `TargetRenderPolicy`
- `TargetRenderBlockedException`
- `TargetReviewArtifactRenderer`
- `FlowRendererFailureSemanticsTests`

## Result

- unresolved renderer payloads produce a non-executable `TargetProjectionReview` document
- blocked or unsupported materialization fails before vendor syntax is returned
- GitHub Actions no longer emits empty green jobs for unresolved work
- Tekton no longer emits a phantom `flow-materialization-required` task reference
- Jenkins no longer emits a target-specific runtime failure pipeline for unresolved work
- executable target syntax requires explicit renderer payload evidence

## Validation boundary

Compatibility status remains separate until v0.9.5.7.5. This repair changes renderer output semantics without claiming additional target implementation coverage.
