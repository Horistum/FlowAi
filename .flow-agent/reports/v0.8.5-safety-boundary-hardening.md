# v0.8.5 Safety Boundary Hardening Report

## Objective

Add a pre-projection safety boundary gate over Flow AST and module contracts.

This release strengthens validation before target rendering while preserving Flow's architecture boundary.

## Scope

Included:

- `SafetyBoundaryValidator` added.
- `FlowValidator` now includes the safety boundary gate.
- Tests added for production-sensitive mutation, high-risk action approval, and rollback-sensitive action approval.
- v0.8.5 release metadata aligned.
- v0.8.5 documentation added.
