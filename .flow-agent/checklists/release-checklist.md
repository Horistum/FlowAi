# Release Checklist

A release is acceptable only if every applicable item is satisfied.

## Required

- [ ] Work package exists.
- [ ] Roadmap item is identified.
- [ ] Architecture checks passed.
- [ ] Forbidden-direction checks passed.
- [ ] Code changes are minimal and reviewable.
- [ ] Tests were added or updated.
- [ ] Conformance vectors were added or updated when applicable.
- [ ] Documentation was updated when applicable.
- [ ] Offline validation was run or limitations were documented.
- [ ] Release report exists.
- [ ] Release state was updated after validation.

## Release Report Must Include

- Objective.
- Scope.
- Files changed.
- Tests changed.
- Conformance changes.
- Architecture compliance.
- Validation results.
- Known limitations.
- Next roadmap item.
