Flow package-line validation note

The package line is defined solely by `version` in build.gradle.kts, and the active public standard
version by FLOW_STANDARD_VERSION in src/main/kotlin/org/flowlang/standard/FlowStandardVersions.kt.
Do not restate either number here; a hardcoded copy only drifts out of date.

Do not rely on historical hardcoded test counts in this file. Validate the current checkout with:

  ./gradlew --no-daemon clean test
  ./gradlew --no-daemon run --args="conformance"

For fully offline validation, provide the same Gradle distribution and dependency cache used by the target environment.
