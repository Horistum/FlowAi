# Flow Core Prototype v0.7.7

v0.7.7 adds scenario pack quality gates on top of v0.7.6.

This release validates scenario pack metadata, example relevance, duplicate identifiers and negative coverage for risk-sensitive automation capabilities.

- `src/main/kotlin/org/flowlang/standard/ScenarioPackQualityAnalyzer.kt`,
- `tests/FlowScenarioPackQualityGateTests.kt`,
- `conformance/standard/scenario-pack-quality-gates.conformance.yaml`,
- `.flow-agent/work-packages/v0.7.7-scenario-pack-quality-gates.yaml`.

The active standard version is `0.7.7`.
