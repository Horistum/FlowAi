# Flow Agent Documentation

The Flow Roadmap Development Agent is a repository-bound control structure for incremental Flow Core development.

It is intentionally simple:

- it defines the project purpose,
- it defines immutable architecture rules,
- it defines the roadmap,
- it defines forbidden directions,
- it defines quality gates,
- it defines the release process.

The agent does not replace engineering judgment.
It prevents uncontrolled architectural drift while allowing AI-assisted implementation.
