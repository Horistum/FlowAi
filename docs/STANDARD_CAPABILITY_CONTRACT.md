# Standard Capability Contract

Status: v0.3.0-rc1.8.3 draft

The Standard Intent Catalog is not only documentation. Each capability is moving toward an executable contract containing:

- category
- maturity
- required design questions
- required params
- optional params
- required systems
- lowering strategy
- target implications

This keeps Flow above individual platforms and prevents high-level intent from degrading into a CI/CD-only template library.
